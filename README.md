# Auspr7ng Portfolio

A simple Vue-powered static portfolio showcasing education, experience, projects, and publications.

## Tech Stack
- Static HTML + CSS
- Vue 3 (CDN build)

## Project Structure
- index.html — main single-page app
- assets/ — images, icons, resume PDF

## Running Locally
1. Clone or download the repo.
2. Open index.html directly in your browser, or serve the folder (e.g., `python -m http.server 8000`).
3. Ensure assets/ stays alongside index.html.

## Customizing
- Content: edit the Vue data in index.html (skills, experiences, projects, pubs).
- Styling: tweak CSS variables and styles in the <style> block of index.html.

## Deployment
Host the folder on any static host (GitHub Pages, Netlify, Vercel). Point the site root to index.html.
